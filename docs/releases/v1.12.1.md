## v1.12.1

Patch release for **GitHub Pulls Show Reviewers** focused on reviewer avatar
chip polish in GitHub pull request lists. This release keeps the product scope
unchanged: requested reviewers, requested teams, and completed review state
remain the only pull-list metadata surfaced by the extension.

### Highlights

- Kept reviewer avatar state rings visible after clicking an avatar chip by
  moving the ring rendering away from click-sensitive box-shadow styling.
- Added a white base behind reviewer avatar artwork so transparent black icon
  avatars stay legible on GitHub's dark pull list backgrounds.

### Authentication

- No permission, token-scope, storage-schema, or host-permission changes.
- Public repositories still work without signing in when GitHub's
  unauthenticated REST API allows it.
- Private repositories continue to use the maintainer-owned GitHub App account
  flow with `Pull requests: Read` access only.

### Quality & Packaging

- Added regression coverage for avatar ring rendering and transparent avatar
  backgrounds.
- Release packaging behavior is unchanged: GitHub Actions still runs the
  release preflight, `pnpm verify:release`, and checked Chrome zip creation
  before attaching the package to the GitHub Release.

### Scope Notes

- Reviewer visibility on GitHub pull request list pages remains the only
  product goal.
- Checks, mergeability, labels, assignees, and general PR dashboard features
  remain out of scope.

## v1.18.10

> Not published. The `v1.18.10` tag's release verification failed on an
> intermittent test before any package, Chrome Web Store or GitHub Release
> step ran. These changes ship in [v1.18.11](./v1.18.11.md).

Maintenance release for **GitHub Pulls Show Reviewers**. The extension's
behavior is unchanged.

### Monitoring

- The weekly live GitHub canary now checks the unauthenticated GitHub API
  quota before each attempt and waits for the reset when an earlier job on
  the same runner already used part of it, instead of reporting that as a
  failure (#326).

### Dependencies and tooling

- Override `minimatch` to 11.x in the lint toolchain to clear the moderate
  advisory GHSA-g3hv-75wg-m249, which Dependabot could not resolve in range.

### Compatibility

- Chrome 140 or later is still required. Permissions, host access, GitHub App
  scope, stored data and all five interface languages are unchanged.
- All five store descriptions and all 15 committed screenshots are unchanged;
  reuse the verified saved-listing baseline. The screenshot recapture is still
  tracked in #319.

## v1.18.4

Packaged E2E diagnostic retention for **GitHub Pulls Show Reviewers**.

### CI and release diagnostics

- Preserve fixture-based E2E traces and diagnostic attachments from regular CI
  and release-source verification for 14 days, using unique run/attempt artifact
  names. Evidence survives both final failures and successful retries.
- Skip uploads when verification did not run or no output exists. Keep the
  existing one-retry policy, first-retry tracing, and separate live GitHub canary
  evidence handling.
- Document artifact download and Trace Viewer inspection in the
  [contributor guide](../../CONTRIBUTING.md#download-packaged-e2e-diagnostics).

### Compatibility and verification

- Extension behavior, permissions, GitHub App scope, stored data, and all five
  interface languages are unchanged.
- Temporary fixture-only persistent-context probes verify downloaded traces,
  browser actions, DOM snapshots, and JSON attachments after failure and retry.
  The intentional probes are removed from the final test suite.
- All five Chrome Web Store descriptions and all 15 screenshots are unchanged;
  existing verified saved listings can be reused.

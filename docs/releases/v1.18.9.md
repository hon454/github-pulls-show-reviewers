## v1.18.9

Options, localization and documentation polish for **GitHub Pulls Show
Reviewers**.

### Options page

- Restore the width and spacing of the description under the options page
  header, and remove style rules that no longer matched anything.
- Keep the display toggles disabled until the saved settings load, so the
  defaults are never shown as if they were your settings. If loading fails,
  the error now offers **Try again**.
- Clear "Account connected." when an account leaves the list, in this tab or
  another, and hide the empty account list while the accounts could not be
  loaded. If **Sign in again** cannot start because sign-in is unavailable in
  the build, the page now says so.
- Press Enter in the repository check field to run the check. Both checks
  accept `owner/name`, a `https://github.com/owner/name` URL and a trailing
  slash, and an input error is announced with the field.
- Keep keyboard focus on a button, toggle or the language menu while it is
  saving. After you remove an account, focus moves to the next account, or to
  **Add another account** when none are left.
- Raise the contrast of the repository field placeholder.

### Languages

- Align Korean, Japanese, Simplified Chinese and Traditional Chinese wording
  with the shared glossary, for example sign-in, rate-limit reset and
  unauthenticated states, and keep device-flow authorization distinct from
  review approval.
- Use CJK sentence punctuation around the authorization management link on the
  options page, remove stray spaces after `。`, use full-width `：` in
  Japanese reviewer labels, and use `…` for every ellipsis.
- Remove an unused message and add a test that keeps every catalog key in use
  and the localization guide's message counts current.

### Dependencies and tooling

- Update zod to 4.6.7, which fixes the production dependency advisory
  GHSA-mrhx-c7xc-m3w5, and React to 19.3.1.
- Update WXT to 0.21.5, Vite to 8.3.5, Vitest to 5.0.5, Playwright to 1.64.1,
  the release-tooling group and the GitHub Actions versions.
- Refresh `AGENTS.md`, `CONTRIBUTING.md` and the READMEs against the current
  tree. The READMEs now link to the release notes instead of naming a version.

### Compatibility

- Chrome 140 or later is still required. Permissions, host access, GitHub App
  scope, stored data and all five interface languages are unchanged.
- All five store descriptions and all 15 committed screenshots are unchanged;
  reuse the verified saved-listing baseline. Screenshots regenerated from this
  source differ in 7 images (the five repository-check screens at pixel level,
  and two Japanese pull request list screens because of the full-width colon),
  so their capture source hashes are left at v1.18.8 and the recapture is
  tracked in #319.

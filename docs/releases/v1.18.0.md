## v1.18.0

More accurate reviewer status and bounded recovery from stalled requests for
**GitHub Pulls Show Reviewers**. This release also includes the development-tool
security maintenance prepared as v1.17.2, which was not separately released.

### Reviewer accuracy

- Keep a requested reviewer visible when the optional GitHub event history is
  incomplete or unavailable. The chip retains its requested appearance and
  search link, preserves the earlier completed review in its tooltip and
  accessible name, and does not show a refresh badge unless a newer request is
  confirmed.
- Preserve that distinction through reviewer data, cache, and display updates
  in English, Korean, Japanese, Simplified Chinese, and Traditional Chinese.

### Bounded recovery

- Bound shared repository metadata and started reviewer-summary work to 30
  seconds, optional review-request event evidence to the parent operation's
  remaining time up to 10 seconds, and dispatched content-script reviewer RPCs
  to 35 seconds.
- Preserve existing reviewer chips and the reload guidance when a required
  operation times out. Timing out does not add automatic retries, reloads,
  account discovery, or a rate-limit-reset retry.

### Verification

- Add deterministic packaged coverage for rendered reviewer outcomes, native
  pull-list pagination, Back navigation, closed-filter navigation, host-empty
  detection, late-response isolation, and retained diagnostic artifacts.
- The final public A→B→C→D live-canary success is not claimed: retained public
  observations encountered GitHub quota exhaustion and test-harness defects
  that were corrected before release. The release acceptance scope was
  explicitly completed with deterministic coverage, exact CI, and independent
  review instead of another live attempt.

### Included maintenance and known development finding

- Include the v1.17.2 Vitest and V8 coverage-provider update to 4.1.11 for
  GHSA-82fw-gwwq-j7x9.
- A fresh release-preparation dependency audit reports zero production findings.
  One moderate development-only finding remains in the WXT Firefox runner path
  through `adm-zip@0.6.0` (GHSA-vwc7-r8mq-g2x9); no patched version is reported
  and upstream remediation remains tracked in [#195](https://github.com/hon454/github-pulls-show-reviewers/issues/195).

### Compatibility

- Existing accounts and display preferences remain supported. No permissions,
  host access, OAuth scope, storage boundary, or reviewer-only product scope is
  added or broadened.
- Public repositories retain no-token access subject to GitHub API limits;
  private repositories continue to use the maintainer-owned GitHub App with
  `Pull requests: Read`.

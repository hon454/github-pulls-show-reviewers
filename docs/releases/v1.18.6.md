## v1.18.6

Repository and release hardening for **GitHub Pulls Show Reviewers**.

### Dependency monitoring

- Restore dependency vulnerability monitoring: Dependabot alerts and security
  updates, grouped weekly version updates for npm and GitHub Actions, and a
  weekly audit that fails only on production advisories and reports the full
  graph.
- Update the packaged runtime dependencies to React 19.3.0 and Zod 4.6.5, and
  the release tooling to `publish-browser-extension` 6.1.1 and
  `google-auth-library` 11.1.0.

### Release trust root

- Enforce the release trust root on GitHub: `main` requires a pull request with
  passing checks, `v*` tags cannot be moved or deleted, and the Chrome Web Store
  key lives in a deployment environment that admits only `main` and `v*` tags.
- Pin every workflow action to a commit SHA, stop persisting checkout
  credentials in release jobs, and check workflow and source ancestry before
  release source code runs.
- Let completed receipts older than the 90-day artifact retention age out of
  the release history, while expired evidence of an incomplete run still stops
  for recovery.

### CI and code quality

- Fix two intermittently timing-out localization E2E specs and report tests
  that pass only on retry in the CI run summary.
- Add a formatting check, job timeouts, read-only CI token permissions, a
  pinned Node.js version, and cancellation of superseded pull-request runs.
- Enable type-aware promise lint rules and React hooks linting.

### Compatibility

- Reviewer display, permissions, GitHub App scope, authentication, stored data
  and all five interface languages are unchanged. Two options-page promise
  call sites were restructured without changing their control flow.
- All five store descriptions and all 15 screenshots are unchanged; reuse the
  verified saved-listing baseline.

## v1.18.5

Live GitHub DOM canary maintenance for **GitHub Pulls Show Reviewers**.

### Independent ListView verification

- Recognize classic and ListView PR rows with an independent structural oracle.
  GitHub's ListView pages no longer fail solely because they lack classic
  `issue_<number>` IDs. Production selectors are used only to compare coverage.
- Preserve failures for missing, duplicate, orphaned or loading mounts,
  inaccurate reviewer state, missing reviewers and incomplete API evidence.
- Add a minimized captured ListView fixture and exercise both layouts in the
  packaged rendered/empty, API-failure and native navigation scenarios.
- Recognize ListView's native `state:closed` filter and classify an observed
  HTTP 403 with exhausted API quota as an environment rate-limit failure.

### Weekly monitoring

- Run the live canary every Monday at 06:17 UTC (15:17 Asia/Seoul), with manual
  dispatch retained. Actual GitHub Actions start times may be delayed.
- Keep read-only permissions, serialized canary runs, two bounded retries and
  14-day failure evidence retention. Live GitHub checks remain separate from
  deterministic PR and release gates.

### Compatibility

- Extension behavior, permissions, authentication, storage and interface
  languages are unchanged.
- All five store descriptions and all 15 screenshots are unchanged; reuse the
  verified saved-listing baseline.
